Навыки и рабочий уровень

Практический уровень по ключевым направлениям сейчас держится в диапазоне 60–80%.

HTML/CSS • 80% HTML & CSS: семантика, адаптивная сетка, flex/grid, карточки, модальные окна, responsive‑проверка и аккуратная верстка под реальные бизнес‑страницы.
JavaScript • 60% JavaScript: DOM, события, карусели, модалки, i18n, плавные действия интерфейса и небольшие инструменты для пользователей.
AI/ML • 80% Искусственный интеллект: GPT, промпт‑инжиниринг, структура контента, анализ, автоматизация рутины, подготовка SEO‑текстов и сценариев для сайтов.
Laravel • 60% Laravel: MVC‑логика, маршруты, Blade, базовая работа с данными и подготовка фундамента для личных кабинетов, форм и внутренних web‑приложений.
CMS • 80% CMS: WordPress, структура страниц, темы, базовые интеграции, безопасность, быстрый запуск корпоративных сайтов, каталогов и блогов.
GitHub • 60% Git & GitHub: ветки, коммиты, публикация изменений, GitHub Actions для деплоя и контроль версий проекта.
UI/UX • 70% UI/UX: логика первого экрана, CTA, сетка, отступы, карточки, мобильная версия, визуальный маршрут клиента и понятная структура страницы.
